## 2. 坐标与格式约定

- **格式**：PDB 为标准固定列宽文本格式；SDF（V2000）为 MDL 结构数据格式，`$$$$` 分隔记录；
  `ZMA.cif` 为 PDBx/mmCIF 化学组分字典条目。
- **坐标单位**：Å（PDB 与 SDF 均为 Å）。
- **链标识**：受体文件链标识为 `A`；MD 后复合物 PDB 的链标识列为空（由 MD 导出流程写入，未重新指派链号）。
- **盒子信息**：两个复合物 PDB 的 `CRYST1` 分别为 `88.200 88.200 116.994 Å` 与
  `87.186 87.186 119.343 Å`（P1 对称），对应各自模拟盒。
- **质子化状态**：沿用上游受体/配体准备的既定状态；本目录文件为**原样复制**，入包时未做任何坐标、
  质子化或键级修改（仅做哈希校验）。
- **复合物范围**：MD 后复合物 PDB 只含受体与配体，不含脂质、水与离子；膜体系相关读数（温度、密度、
  每脂质面积等）登记在上游 SOP-05 报告与 `results/` 其他目录中。

## 3. 来源与校验

- 全部文件取自本项目 2026-09 SOP-05（含膜 MD 与 MM-GBSA 复核）批次的结构产物；
- 入包时逐文件比对**文件大小与 sha256**，源副本与本包副本一致，记录见 `logs/RUN_RECORD.md` §5；
- 本目录只补充三维结构证据，不改动候选清单、门、阈值与任何既有中间产物。
