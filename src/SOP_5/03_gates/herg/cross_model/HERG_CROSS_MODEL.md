# hERG 第二模型交叉验证（模型依赖度）

本步在**同一 3,236 个四臂并集分子**上跑一组独立实现的模型，用于量化主门（ADMET-AI 单模型 hERG<0.5）在多大程度上依赖被选中的那一个模型。

## 1. 第二模型的数据与训练

- 数据：ChEMBL REST API，靶点 CHEMBL240 (KCNH2 / hERG, Homo sapiens)（KCNH2/hERG），抓取于 2026-09-23T06:47:45Z，原始记录 13521 条（sha256 `71b1852e9e5548fc…`）
- 标注：pChEMBL ≥ 6.0 → 阻断剂；≤ 5.0 → 非阻断剂；中间模糊带丢弃 → 标注 6057 个（阻断 2411 / 非阻断 3646）
- 特征：ECFP4 2048 bit（RDKit）（不含 ADMET-AI 的任何权重或特征）

## 5. 独立性声明与转述要求

- ADMET-AI 的 hERG 头同样基于公开 hERG 数据（含 TDC hERG 集，多源自 ChEMBL）训练，故本步量化的是算法/训练管道依赖度，不构成数据独立的外部验证
- 因此上表的一致性度量的是**算法/训练管道依赖度**，不能替代真正数据独立的外部验证；两模型一致说明结论对该类模型稳健，不一致的分子应在 MD 前置复核中按「模型依赖」逐个人工核对。
