## 必须随结果转述的口径

1. **这批分子是 ML 生成 + 对接打分**，走的是同一套门；包内**不含任何实验数据**，本层不产生安全性或有效性结论。
2. **hERG 只是单一模型的分类线**：`hERG` 与 `hERG_drugbank_approved_percentile` 出自同一模型，后者只是已上市药百分位换算，**不构成第二模型或独立验证**。只能说「在 ADMET-AI 下过门」。第二模型（ChEMBL 自建集成）与主模型 κ≈0.07，17 个候选中有 8 个在第二模型下不过门——这些分子已**保留入池并逐分子标注**「模型依赖」（见 `md_eligibility_note` 列），机时代价约 +0.8 卡日量级。
3. **「最优」限定在批次目标函数口径内**：MILP 证书证明的是「在配额可行域内按 分层覆盖 t → CNN_VS 跨度 → Σ CNN_VS 字典序最优」，**不是**「这批分子比其余候选更好」。低分位（CNN_VS Q1）分子入批后失败概率更高，这正是要测量的量。
4. **结构性发现（run05 特有）**：资格池 25 个分子的化学型为 16/5/4，帽 8、名额 17 ⇒ 可填上限恰为 8+5+4 = **17，零冗余**，故 9 个席位被结构性锁定；反事实重解显示禁掉这 9 席中任一个，可行域直接为空（覆盖不可替代 9、跨度不可替代 1、可替代 7）。这不是求解失败，而是帽值与名额咬合的结果，已在 `07_md_batch/reports/md_batch.json` 登记。
5. **阈值/门未变，随数据更新的是登记值**：`list_size=50`、化学型帽 20、风险档 8 仍按**设计目标**口径保留（不随实测规模重算，否则约束逐轮收缩不收敛）；实测名单规模 32+2 由池与约束共同决定。
