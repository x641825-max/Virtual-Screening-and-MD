# hERG 阈值选择 SOP（包内版本 · 步骤 3e / 分析步 10c）

**目的**：把「用 hERG 过滤分子」的阈值选择变成一次可复现、可审计、可迁移的流程。
**本版本依据**：包内冻结的 ADMET-AI f3 库表（49,963 分子 × 105 个 ADMET 列，sha256 `5d693ea7d9d06e29…`）与其中的已上市药参照百分位列。
**性质**：分析步——主口径 `hERG < 0.5` 不变，本步只产出决策证据。

## 1 三个锚定各自回答什么（分工，不是三选一）

| 锚定 | 回答的问题 | 角色 | 本包取值 |
|---|---|---|---|
| ① 库内相对 | 在这批分子里它排在哪 | 排序层（不做硬线） | 库 75/90 分位 = 0.764326 / 0.877107；池 75/90 分位 = 0.755885 / 0.857625 |
| ② 已上市药参照 | 相对已上市药算不算差 | 解释层（软线 + 合理性窗口） | 50/75/90 分位 = 0.294387 / 0.743738 / 0.931979 |
| ③ 取舍驱动 | 过滤会牺牲多少对接头部 | 决策层（硬线候选） | 库级头部 0.8；本包主池头部 0.75 |

## 2 执行步骤（确定性）

1. **定硬线（③）**：在 0.01 网格上取「保住对接前 K=1000 名 ≥ 75%」的最严阈值 → 0.8（0.01 网格精确解 0.79），再按 0.05 网格取整以免贴边。
2. **合理性窗口（②）**：硬线须落在 [A2@50, A2@90] = [0.294387, 0.931979] → 通过。
3. **定软线（②）**：软线 = 参照集 75 分位 = 0.743738（表述：「不差于 3/4 的已上市药」）。
4. **输出排序列（①）**：附库内百分位，供系列内挑类似物使用。

## 3 冲突消解规则（其他库/其他项目出现分歧时）

- 若 ③ 解 > ② 的 90 分位 → **以 90 分位封顶**（不允许为了保对接头部突破「不劣于 90% 已上市药」底线）。
- 若 ③ 解 < ② 的 50 分位 → 说明对接头部整体偏「比一半已上市药还差」，
改用参照集 75 分位作硬线，并回头检查打分与化学空间。
- 若 ① 与 ② 相差 > 20 个百分位 → 库整体偏移严重，对外一律用 ② 表述。
- 任何情况下 ① 不单独决定过滤。

本轮分支判定：**none（A3 落在合理性窗口内）**。

## 4 本包当前判定（不改门，仅标注）

## 4b 门作用域缺口（非判据，量化保守口径的代价）

落门表 `03_gates/herg/herg_predictions.csv` 只覆盖四臂并集 3236 个分子；池内1754 个分子在并集之外（无预测值）→ 按规则保守判为不过门。本包冻结的 f3 全量表给出了这些分子的 ADMET-AI hERG：其中 **480 个（27.366%）实际 < 门阈值 0.5**，即被保守口径排除。落门表与冻结表在同源交集（3236 个）内逐值一致（max|Δ| = 1e-06）。

这些分子**不在任何臂/名单内**，本项只作透明度披露：若要改作用域，属口径变更（需重跑选名单与验收基线），本步不改门、不改名单。

## 6 变更控制

- 必须重跑本流程的情形：合并/更换化合物库；ADMET 冻结表重算（模型或版本变化）；对接排名更新；`grid`/`min_keep`/`primary_top_k`/`round_step` 改动。
- 阈值只在 0.05 网格取值（避免贴边解）；每次变更在 decision JSON 与本文件中留痕。
- 冻结项：软线、硬线候选、判定字典（除非流程重跑，不得手改）。

## 7 局限

- hERG 预测未做概率校准；硬线候选是「本包库 + 本对接目标」下的操作点，**迁移到其他项目必须重跑本流程**。
- 库内相对锚定（①）在本包以 f3 49,963 行为口径；外部流程报告用的是54,932 去重并集，数字会有小差异（不影响②③）。
- 本流程只做优先级与标注；最终结论需离子通道实验（膜片钳等）确认。
