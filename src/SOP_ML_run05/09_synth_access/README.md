# 09_synth_access · run05 名单可合成性评估（步骤 16）

派生分析层。给 run05 主链选出的名单补一层**离线、确定性**的可合成性读数：
每个分子一条 SAScore、一组结构难点旗标、一个分诊带，以及来源标注。

**本层不改名单、不改门、不改规则版本**——只出证据，供人工分诊用。
口径与 SOP_5 的 `09_synth_access/` 逐条一致（SA 分带 4.0 / 6.0、8 条难点线、分诊带阈值均未改），
可直接与 SOP_5 对照；随数据变化的只有实测统计量。

## 2. 三套口径

| 口径 | 实现 | 说明 |
| --- | --- | --- |
| SAScore | RDKit `Contrib/SA_Score/sascorer.py`（本机分发） | Ertl & Schuffenhauer 2009 的复杂度–片段贡献启发式分，1（易）→ 10（难）；**官方未给分档**，本层用 4.0 / 6.0 作经验分带 |
| 复杂旗标 | 8 条确定性结构规则 | 硬旗标：`stereo_ge4`（立体中心 ≥ 4）、`bridgehead`（桥环原子）、`macrocycle`（环 ≥ 12）、`rare_element`（C/N/O/S/F/Cl/Br/I/P 之外元素）；软旗标：`stereo_2_3`、`fused_tricyclic`（最大稠合环系 ≥ 3 环）、`spiro`（螺环原子 ≥ 2）、`ring_rich`（环数 ≥ 5） |
| 来源标注 | cid 前缀 | ZINC / MCULE = 可按需合成目录；PubChem CID = 实体已知化合物；**SCALE- = 生成模型输出（run05 新增分支，无目录来源可标）**。**不等于现货可得**，本层无法离线核验库存或报价 |

分诊带（本层自定经验带，随报告落盘以便复核，与 SOP_5 同阈值）：

- **橙 优先人工评估** = SA > 6.0 或命中任一硬旗标或软旗标 ≥ 3
- **黄 需确认路线** = 4.0 < SA ≤ 6.0 或软旗标 1–2
- **绿 常规合成** = SA ≤ 4.0 且无旗标

## 3. 核心读数（run05）

| 项 | run05（32 候选） | SOP_5（48 候选，同口径基线） |
| --- | --- | --- |
| SA 中位 / 均值 / std | **2.825 / 2.812 / 0.224** | 2.726 / 2.738 / 0.295 |
| SA 范围 | **2.213–3.145** | 2.197–3.547 |
| SA 分档 | 易 **32** / 中 0 / 难 0 | 易 48 / 中 0 / 难 0 |
| 分诊 | 绿 **32** / 黄 **0** / 橙 **0** | 绿 40 / 黄 8 / 橙 0 |
| 旗标命中 | **8 条全部 0 命中**（硬旗标 0） | 命中 3 条，8 个候选被标记（硬旗标 0） |
| 来源标注 | 生成模型输出 32（**无目录来源**）/ PubChem CID 2 | ZINC / MCULE / PubChem CID |
| MD 席（17） | SA 均值 2.85 / 最大 3.145、标记 0、绿 17 | 18 席：均值 2.722 / 最大 3.547、标记 5、绿 13 / 黄 5 |

**本层在 run05 名单上无区分度**：SA 全落「易」档且区间比 SOP_5 更窄，8 条难点线**一条都没命中**，
所以分诊必然全绿。原因写实：这批 ML 生成分子**全部无立体中心**（`n_stereo_total` 恒为 0）、
环数 3–4（< 5，不触发 `ring_rich`）、最大稠合环系 ≤ 2 环（不触发 `fused_tricyclic`）、
分子量集中（重原子 19–28）。这不是漏检，是名单未触及这些难点。

SA 最高的 5 个候选（全部无旗标、全绿带）：
`SCALE-108881` 3.145（**在 MD 批次内**）、`SCALE-101054` 3.143、`SCALE-116071` 3.093、
`SCALE-111400` 3.084、`SCALE-032087` 3.070。

**对照位置是关键读数**：`C60359994` SA **3.776**，高于全部 32 个候选——一个已被合成出来的真实
化合物在 SA 上比所有候选都「难」，说明 2.2–3.1 区间内的 SA 排序**不具备可合成性含义**。
`C09462894` SA 2.454 落在候选区间内（5 环 → 软旗标 `ring_rich`，但对照不进分诊）。
两个对照均带旗标而候选一个都没有，也说明旗标口径与「真实分子」无关。

**内部一致性补算**（SOP_5 步骤 16 亦做过的同名补算，本层落盘；不是第四套口径）：
名单内 SA 与结构描述符的 Spearman ρ = `n_rings` **+0.472**、`qed` **−0.429**、
`cns_mpo` −0.292、`MW` +0.276、`n_heavy` +0.147、`CNN_VS` +0.095。
比 SOP_5（全部 |ρ| ≤ 0.16）明显，即本名单的 SA 主要跟着环数与 QED 走——仍然只是片段贡献的
加和噪声，不能读成可合成性排序。

## 7. 如何解读本层读数（「好坏」怎么判）

**先分清三种问题**，它们答案不同：

| 问题 | 本层能否回答 |
| --- | --- |
| 这个分子本身可合成性好不好？ | **不能**。只能答「启发式未报警」 |
| 这个分子的读数在名单里算好还是差？ | **run05 不能**：SA 无区分度、旗标零命中，名单内没有「差」的一端 |
| 这层评估本身做得够不够好？ | 能，见 §8 的判别清单 |

单个候选的读法：**看分诊带，不看 SA 的绝对数值**。

| 带 | 含义 | 动作 |
| --- | --- | --- |
| 橙 | 命中硬旗标 / SA > 6 / 软旗标 ≥ 3 | 优先人工评估路线（run05：0 个） |
| 黄 | SA 4–6 或软旗标 1–2 | 交合成同事看路线，按旗标类型排优先级（run05：0 个） |
| 绿 | SA ≤ 4 且无旗标 | **「未发现红旗」，不是「确认好合成」——绿带是无信息，不是正面结论** |

run05 的 32 个候选**全部落在绿带**，即本层对这批分子只交付了一个结论：
**启发式红旗扫描未报警**。任何「这批分子可合成性好」的说法都超出了本层证据范围。

## 9. 限制（引用读数时必须一并说明）

- SA 是启发式复杂度分：**不含**路线、原料可得性、保护基策略与手性拆分代价；SA ≤ 4 不等于「立刻可买」。
- 旗标是确定性结构规则，命中的分子并非「不可合成」，只表示需要人工看路线；run05 全部零命中
  **不等于**这批分子一定好合成，只表示它们没触及本层的 8 条难点线。
- **来源标注这一套在 run05 不可用**：32 个候选是 ML 生成分子（`SCALE-` 前缀），没有 ZINC / MCULE /
  PubChem CID 那样的目录来源可标；SOP_5 名单上的「可按需合成目录 vs 实体化合物」读法不能平移过来。
- 分诊带与 SA 分档都是**本层自定经验阈值**，不是论文判据；定义已随 JSON / MD 落盘。
- 本层与门控/筛选口径无关：**不改变** run05 主名单（32 候选 + 2 对照）与 MD 批次（17 席）的构成与排序。
- 本层只对**名单**做读数，不含全池背景分位（4,979 全池 / 751 资格池的 SA 分布未纳入），
  因此不能回答「名单分子在池内处于什么位置」。
