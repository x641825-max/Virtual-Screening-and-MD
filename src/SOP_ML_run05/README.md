# SOP_ML_run05 · A2A 拮抗剂 MD 候选名单（ML 生成分子换数据链）

自包含、结构化、可复现。**与 `SOP_5` 共用同一套脚本、阈值与门**（规则
`SOP-05-A2A-antagonist-shortlist` **v1.7.0，一字未改**），只换一个输入表：

```text
00_inputs/raw/inputs/CNN_VS_ranking_49963_with_pKa_cLogD74.csv   ← 4,979 个 ML 生成分子（SCALE-）
00_inputs/raw/inputs/top5000_best_pose.sdf                        ← 同批 4,979 个 gnina 最优姿态
```

两条链的分子来源**互斥**：本链是生成模型分子，`SOP_5` 是目录化合物（ZINC/MCULE）。
按 InChIKey 核对，两份 MD 一级批次**结构零重叠**（唯二相同的是 2 个共用阴性对照）。

---

## 1. 一句话说明

从 4,979 个已由 gnina 打分的 ML 生成分子出发，跑与 `SOP_5` 完全同一套门禁与约束，
产出 **32 候选 + 2 对照的主名单**，再由 MILP 字典序求解挑出 **17 候选 + 2 对照的 MD 一级批次**。

## 2. 筛选漏斗（实测，逐层剔除）

| 层 | 判据 | 剩余 |
|---|---|---:|
| 0 | 去重后池（InChIKey 唯一） | **4,979** |
| 1 | 类药性硬门（PAINS0 ∧ Ro5 ∧ Veber 零违规） | 4,061 |
| 2 | 姿态闸门 pass | 3,962 |
| 3 | 锚点接触 = 4/4 | 2,971 |
| 4 | maxTc(对已知 A2A 活性物) < 0.90 | 2,955 |
| 5 | QED ≥ 0.50（主池） | 2,404 |
| 6 | hERG < 0.5（ADMET-AI，全池覆盖 4,979/4,979） | 762 |
| 7 | novelty 门：剔除与 ChEMBL 已知 A2A 配体精确重合者 −11 | **751** |
| 8 | 名单层：骨架唯一（≤1/骨架）、成对 ECFP4 Tc < 0.65、化学型 ≤20、AM1-BCC 风险档 ≤8 | **32 候选 + 2 对照** |

## 5. 必须随结果转述的口径

1. 本链分子是 **ML 生成 + gnina 对接打分**，包内**不含任何实验数据**，不产生安全性或有效性结论。
2. **hERG 只是单一模型的分类线**：`hERG` 与 `hERG_drugbank_approved_percentile` 出自同一模型，
   后者只是已上市药百分位换算，**不构成第二模型或独立验证**。第二模型（ChEMBL 自建集成）
   与主模型 κ≈0.07，17 个候选中有 8 个在第二模型下不过门——这些分子**保留入池并逐分子标注
   「模型依赖」**（见 `md_eligibility_note` 列）。正交出口是膜片钳。
3. **「最优」限定在批次目标函数口径内**：MILP 证书证明的是「在配额可行域内按
   分层覆盖 t → CNN_VS 跨度 → Σ CNN_VS 字典序最优」，**不是**「这批分子比其余候选更好」。
   低分位（CNN_VS Q1）分子入批后失败概率更高，这正是要测量的量。
4. **跨来源 CNN_VS 不可直接与 `SOP_5` 比**：本链的池是生成库全范围（0.963–8.536），
   `SOP_5` 的池是目录池按 CNN_VS 截断的 top-4,990（下限 6.554）。联合层已给出
   「来源池内百分位」敏感性对照（见 `src/SOP_5/10_final_md/`）。
5. **阈值/门未变，随数据更新的是登记值**：`list_size=50`、化学型帽 20、风险档 8 按**设计目标**
   口径保留；实测名单规模 32+2 由池与约束共同决定。
