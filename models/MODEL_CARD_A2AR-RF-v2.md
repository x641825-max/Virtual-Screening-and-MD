# A2AR 虚拟筛选机器学习初筛模型档案卡 (Model Card)

## 1. 模型基本信息
- **模型名称**：人源 A2A 腺苷受体（ADORA2A）拓扑特征富集排序模型 (A2AR-RF-v2)
- **模型架构**：随机森林分类器（Random Forest, 400 棵决策树, `min_samples_leaf=2`, `class_weight='balanced_subsample'`）
- **特征工程**：RDKit ECFP4 分子指纹（Morgan 半径 $r=2$, **2048 位 BitVector**, 无手性）
- **便携化封装**：纯 `numpy` 零依赖推理包 `models/a2a_rf_v2_portable.npz` (体积 4.59 MB, 与 scikit-learn 浮点精度一致误差 < 1e-15)
- **对应版本**：v2.0 (2026-09)

## 2. 训练数据与清洗防泄漏规范
- **训练数据来源**：ChEMBL (v33+) 人源 A2AR 定量测定活性分子 + 实验文献经过生物验证的同系列真实非活性物 + 1:1 匹配诱饵。
- **训练集规模**：**4,975 个经过严格化学清洗的高置信度活性样本**与平衡阴性样本。
- **去重与防泄漏措施**：
  - 对所有分子进行规范化去盐（Desalt）与互变异构体标准化；
  - 训练集、验证集与独立测试集严格按照 **Bemis-Murcko 骨架（Scaffold Split）** 进行物理隔离拆分，彻底杜绝相同骨架分子跨集合泄漏导致的人工富集虚高。

## 3. 独立外部泛化测试集实测性能
在 2,167 个未见独立外部测试集（包含 **167 个训练不可见的双拮抗剂全新化学型** + 2,000 个 held-out 诱饵）上的实测指标：
- **ROC-AUC**：**0.987**
- **PR-AUC**：**0.946**
- **BEDROC (α=20)**：**0.859**
- **截断工作点**：保留库的前 10% 时，真活性物召回率达 **92.8%**，入选精确度达 **71.4%**；保留前 5% 时精确度达 **100%**。
- **冻结测试集全新骨架子集表现**：AUC 达 **0.9355 ~ 0.9463**，全新骨架前 1% 精确率达到 **100%**。

## 4. 适用范围与边界局限说明
1. **这是富集排序器，而非绝对结合自由能预测器**：模型输出概率用于在大规模库中进行高通量粗粒度过滤，不能直接代替实验测定的亲和力 Kd 或 IC50。
2. **靶点特异性**：该模型仅针对 A2AR 设计，不具备推断 A1/A2B/A3 亚型选择性的能力。
3. **互补协同机制**：实测表明该 2D 拓扑模型在已知化学类似物上捕获率极高，必须结合 3D GNINA 分子对接进行**秩平均 (Rank Averaging)** 协同，方可实现全新骨架与已知类似物的均衡挖掘。
